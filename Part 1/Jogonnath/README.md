## কাজের বিবরণ

Lexer (শাব্দিক বিশ্লেষক) হলো কম্পাইলারের প্রথম ধাপ। `.bsc` ফাইল পড়ে প্রতিটি অর্থবহ অংশকে **টোকেন**-এ রূপান্তরিত করে।

### Lexer যা করে:
- বাংলা কীওয়ার্ড চেনে: `ধরি`, `সংখ্যা`, `দশমিক`, `দেখাও`, `যদি`, `নাহলে`, `শুরু`, `শেষ`
- বাংলা পরিচয়কারক চেনে: `বয়স`, `যোগফল`, `গণক`
- বাংলা সংখ্যা চেনে: `০` `১` ... `৯` এবং `৩.১৪`, `৫.৫`
- টোকেন স্ট্রিম তৈরি করে Parser-এর জন্য

### টোকেনের প্রকার:
| টোকেন | উদাহরণ |
|--------|---------|
| কীওয়ার্ড | `ধরি`, `যদি`, `দেখাও` |
| ধরন | `সংখ্যা`, `দশমিক` |
| পরিচয়কারক | `বয়স`, `যোগফল` |
| পূর্ণসংখ্যা | `১০`, `৫`, `১০০` |
| দশমিকসংখ্যা | `৩.১৪`, `৫.৫` |
| বর্ণমালা | `"স্বাগতম"` |
| অপারেটর | `+`, `-`, `*`, `/`, `=`, `==`, `!=`, `<`, `>`, `<=`, `>=` |

## উদাহরণ প্রোগ্রাম

### চলক ও গণিত
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ৫;
ধরি সংখ্যা তৃতীয় = ২;
ধরি সংখ্যা ফল = প্রথম + দ্বিতীয় * তৃতীয়;
দেখাও "গণনার ফল:";
দেখাও ফল;
```
**আউটপুট:** `২০`

### শর্ত পরীক্ষা
```
ধরি সংখ্যা বয়স = ১৬;
যদি (বয়স > ১৭) শুরু
    দেখাও "আপনি ভোট দিতে পারবেন!";
শেষ
নাহলে শুরু
    দেখাও "আপনি ভোটের বয়স হয়নি।";
শেষ
```
**আউটপুট:** `আপনি ভোটের বয়স হয়নি।`

### বৃত্তের ক্ষেত্রফল (দশমিক)
```
ধরি দশমিক পাই = ৩.১৪১৬;
ধরি দশমিক ত্রিজ্যা = ৫.৫;
ধরি দশমিক ক্ষেত্রফল = পাই * ত্রিজ্যা * ত্রিজ্যা;
দেখাও "বৃত্তের ক্ষেত্রফল:";
দেখাও ক্ষেত্রফল;
```
**আউটপুট:** `৯৫.০৩৩৪`

### মান পরিবর্তন (Swap)
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ২৫;
ধরি সংখ্যা অস্থায়ী = প্রথম;
প্রথম = দ্বিতীয়;
দ্বিতীয় = অস্থায়ী;
দেখাও "পরিবর্তনের পরে প্রথম:";
দেখাও প্রথম;
দেখাও "পরিবর্তনের পরে দ্বিতীয়:";
দেখাও দ্বিতীয়;
```
**আউটপুট:** `২৫` তারপর `১০`

## Lexer টোকেন আউটপুট (--tokens মোড)

```cmd
build\banglasyntax.exe examples\math_test.bsc --tokens
```
```
--- টোকেন স্ট্রিম ---
  [কীওয়ার্ড 'ধরি' লাইন:১ কলাম:১]
  [ধরন 'সংখ্যা' লাইন:১ কলাম:৬]
  [চলক 'প্রথম' লাইন:১ কলাম:১২]
  [নির্ধারণ '=' লাইন:১ কলাম:১৭]
  [পূর্ণসংখ্যা '১০' লাইন:১ কলাম:১৯]
  [সেমিকোলন ';' লাইন:১ কলাম:২১]
```
