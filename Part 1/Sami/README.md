## কাজের বিবরণ

Code Generator (কোড তৈরিকারক) হলো কম্পাইলারের চতুর্থ ও শেষ ধাপ। Semantic Analyzer থেকে পাওয়া যাচাইকৃত AST থেকে **Python কোড** তৈরি করে।

### Code Generator যা করে:
- AST-এর প্রতিটি নোড পড়ে সমমানের Python কোড তৈরি করে
- **চলক ঘোষণা:** `ধরি সংখ্যা ক = ১০` → `ক = int(10)`
- **নিয়োগ:** `ক = ক + ১` → `ক = (ক + 1)`
- **শর্ত:** `যদি (বয়স > ১৭) শুরু ... শেষ` → `if (বয়স > 17): ...`
- **প্রিন্ট:** `দেখাও যোগফল` → `দেখাও(যোগফল)` (বাংলা সংখ্যায় আউটপুট)
- উৎপন্ন Python ফাইলে বাংলা সংখ্যা রূপান্তরকারী যোগ করে
- ইন্ডেন্টেশন সঠিকভাবে বজায় রাখে


## উদাহরণ প্রোগ্রাম

### চলক ও গণিত
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ৫;
ধরি সংখ্যা তৃতীয় = ২;
ধরি সংখ্যা ফল = প্রথম + দ্বিতীয় * তৃতীয়;
দেখাও "গণনার ফল:";
দেখাও ফল;
```
**আউটপুট:** `গণনার ফল:` → `২০`

### শর্ত পরীক্ষা
```
ধরি সংখ্যা বয়স = ১৬;
যদি (বয়স > ১৭) শুরু
    দেখাও "আপনি ভোট দিতে পারবেন!";
শেষ
নাহলে শুরু
    দেখাও "আপনি ভোটের বয়স হয়নি।";
শেষ
```
**আউটপুট:** `আপনি ভোটের বয়স হয়নি।`

### বৃত্তের ক্ষেত্রফল (দশমিক)
```
ধরি দশমিক পাই = ৩.১৪১৬;
ধরি দশমিক ত্রিজ্যা = ৫.৫;
ধরি দশমিক ক্ষেত্রফল = পাই * ত্রিজ্যা * ত্রিজ্যা;
দেখাও "বৃত্তের ক্ষেত্রফল:";
দেখাও ক্ষেত্রফল; 
```
**আউটপুট:** `বৃত্তের ক্ষেত্রফল:` → `৯৫.০৩৩৪`
