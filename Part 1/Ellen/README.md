## কাজের বিবরণ

Semantic Analyzer (অর্থ বিশ্লেষক) হলো কম্পাইলারের তৃতীয় ধাপ। Parser থেকে পাওয়া AST বিশ্লেষণ করে **ধরন পরীক্ষা** এবং **চলক ঘোষণা** যাচাই করে।

### Semantic Analyzer যা করে:
- চলক দ্বিতীয়বার ঘোষণা করা হয়েছে কিনা পরীক্ষা করে
- অঘোষিত চলক ব্যবহার হয়েছে কিনা ধরে
- ধরন মিলছে কিনা পরীক্ষা করে (`সংখ্যা` বনাম `দশমিক`)
- চলকের মান সঠিক ধরনে নিয়োগ হচ্ছে কিনা যাচাই করে

### ত্রুটির উদাহরণ:
```
ধরি সংখ্যা বয়স = ১৮;
ধরি সংখ্যা বয়স = ২০;   ← ত্রুটি: 'বয়স' আগেই ঘোষণা করা হয়েছে
```
```
দেখাও অজানাচলক;          ← ত্রুটি: 'অজানাচলক' ঘোষণা করা হয়নি
```

## উদাহরণ প্রোগ্রাম

### চলক ও গণিত
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ৫;
ধরি সংখ্যা তৃতীয় = ২;
ধরি সংখ্যা ফল = প্রথম + দ্বিতীয় * তৃতীয়;
দেখাও "গণনার ফল:";
দেখাও ফল;
```
**আউটপুট:** `২০`

### শর্ত পরীক্ষা
```
ধরি সংখ্যা বয়স = ১৬;
যদি (বয়স > ১৭) শুরু
    দেখাও "আপনি ভোট দিতে পারবেন!";
শেষ
নাহলে শুরু
    দেখাও "আপনি ভোটের বয়স হয়নি।";
শেষ
```
**আউটপুট:** `আপনি ভোটের বয়স হয়নি।`

### বৃত্তের ক্ষেত্রফল
```
ধরি দশমিক পাই = ৩.১৪১৬;
ধরি দশমিক ত্রিজ্যা = ৫.৫;
ধরি দশমিক ক্ষেত্রফল = পাই * ত্রিজ্যা * ত্রিজ্যা;
দেখাও "বৃত্তের ক্ষেত্রফল:";
দেখাও ক্ষেত্রফল;
```
**আউটপুট:** `৯৫.০৩৩৪`
