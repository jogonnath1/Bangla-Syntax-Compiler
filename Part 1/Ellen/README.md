## কাজের বিবরণ

Semantic Analyzer (অর্থ বিশ্লেষক) হলো কম্পাইলারের তৃতীয় ধাপ। এটি AST বিশ্লেষণ করে অর্থগত সঠিকতা যাচাই করে।

### Semantic Analyzer যা করে:
- **Symbol Table** তৈরি করে (প্রতিটি চলকের নাম, ধরন ও অবস্থান)
- চলক ঘোষণা না করে ব্যবহার করলে ত্রুটি দেখায়
- একই নামে দুইবার ঘোষণা করলে ত্রুটি দেখায়
- **ধরন অসংগতি** (type mismatch) ধরে
- দশমিক মান সংখ্যা চলকে দিলে ত্রুটি দেখায়

### ত্রুটির প্রকার:
| ত্রুটি | উদাহরণ |
|--------|---------|
| অস্বীকৃত চলক | `x = ভূত + 5;` → "অস্বীকৃত চলক 'ভূত'" |
| পুনরায় ঘোষণা | `ধরি সংখ্যা x = 1; ধরি সংখ্যা x = 2;` |
| ধরন অসংগত | `ধরি সংখ্যা n = 3.14;` |

## উদাহরণ

```
// সঠিক কোড
ধরি সংখ্যা x = 10;
x = x + 5;
দেখাও x;

// ভুল কোড — ত্রুটি দেখাবে
ধরি সংখ্যা টাকা = 100;
টাকা = 3.5;   // [অর্থগত ত্রুটি] ধরন অসংগত!
```
