## কাজের বিবরণ

পর্ব ২-তে Semantic Analyzer পর্ব ১-এর সব যাচাই রেখে **`যতক্ষণ`** লুপের ভেতরেও চলক ঘোষণা ও ধরন যাচাই সমর্থন যোগ করেছে।

### পর্ব ২-এ নতুন যা যোগ হয়েছে:
- `যতক্ষণ` লুপের শর্ত যাচাই
- লুপ বডির ভেতরে `ধরি` চলক যাচাই
- লুপ বডির ভেতরে নিয়োগ ও প্রিন্ট যাচাই

## উদাহরণ প্রোগ্রাম

### ১ থেকে ১০ এর যোগফল
```
ধরি সংখ্যা সীমা = ১০;
ধরি সংখ্যা যোগফল = ০;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= সীমা) শুরু
    যোগফল = যোগফল + গণক;
    গণক = গণক + ১;
শেষ

দেখাও "১ থেকে ১০ এর যোগফল:";
দেখাও যোগফল;
```
**আউটপুট:** `৫৫`

### ফ্যাক্টরিয়াল
```
ধরি সংখ্যা মান = ৫;
ধরি সংখ্যা ফ্যাক্টরিয়াল = ১;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= মান) শুরু
    ফ্যাক্টরিয়াল = ফ্যাক্টরিয়াল * গণক;
    গণক = গণক + ১;
শেষ

দেখাও "৫ এর ফ্যাক্টরিয়াল:";
দেখাও ফ্যাক্টরিয়াল;
```
**আউটপুট:** `১২০`

### ধরন ভুলের উদাহরণ
```
ধরি সংখ্যা টাকা = ১০;
টাকা = ৫.৫;
```
**Semantic ত্রুটি:** `সংখ্যা` চলকে দশমিক মান দেওয়া যাবে না

### অঘোষিত চলকের উদাহরণ
```
ধরি সংখ্যা ক = ১০;
ক = ভূত + ৫;
```
**Semantic ত্রুটি:** `ভূত` চলক ঘোষণা করা হয়নি
