## উদাহরণ প্রোগ্রাম

### চলক ও গণিত
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ৫;
ধরি সংখ্যা তৃতীয় = ২;
ধরি সংখ্যা ফল = প্রথম + দ্বিতীয় * তৃতীয়;
দেখাও "গণনার ফল:";
দেখাও ফল;
```
**আউটপুট:** `২০`

### শর্ত পরীক্ষা
```
ধরি সংখ্যা বয়স = ১৬;
যদি (বয়স > ১৭) শুরু
    দেখাও "আপনি ভোট দিতে পারবেন!";
শেষ
নাহলে শুরু
    দেখাও "আপনি ভোটের বয়স হয়নি।";
শেষ
```
**আউটপুট:** `আপনি ভোটের বয়স হয়নি।`
