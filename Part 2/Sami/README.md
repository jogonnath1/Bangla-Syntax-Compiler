## কাজের বিবরণ

Code Generator (কোড তৈরিকারক) হলো কম্পাইলারের চতুর্থ ও শেষ ধাপ। এটি Semantic Analyzer এর যাচাই করা AST নিয়ে **Python কোড** তৈরি করে।

### Code Generator যা করে:
- AST নোড থেকে সরাসরি Python কোড তৈরি করে
- বাংলা চলকের নাম হুবহু রাখে
- বাংলা স্ট্রিং হুবহু রাখে (UTF-8)
- `ধরি` → Python variable assignment
- `দেখাও` → `print()`
- `যদি/নাহলে` → `if/else`
- `যতক্ষণ` → `while`

### রূপান্তরের নিয়ম:
| বাংলা সিনট্যাক্স | Python আউটপুট |
|------------------|----------------|
| `ধরি সংখ্যা x = 10;` | `x = 10` |
| `দেখাও "হ্যালো!";` | `print("হ্যালো!")` |
| `যদি (x > 0) শুরু` | `if x > 0:` |
| `যতক্ষণ (i < 10) শুরু` | `while i < 10:` |

## উদাহরণ

**ইনপুট (.bsc):**
```
ধরি সংখ্যা যোগফল = 0;
ধরি সংখ্যা i = 1;
যতক্ষণ (i <= 5) শুরু
    যোগফল = যোগফল + i;
    i = i + 1;
শেষ
দেখাও যোগফল;
```

**আউটপুট (.py):**
```python
# Generated by Bangla Syntax Compiler
যোগফল = 0
i = 1
while i <= 5:
    যোগফল = যোগফল + i
    i = i + 1
print(যোগফল)
```

## ফাইল কাঠামো

```
Sami/
├── src/
│   ├── token.h          ← টোকেনের সংজ্ঞা
│   ├── lexer.h/.cpp     ← শাব্দিক বিশ্লেষক (জগন্নাথ)
│   ├── ast.h            ← AST নোড
│   ├── parser.h/.cpp    ← সিনট্যাক্স বিশ্লেষক (সায়েম)
│   ├── semantic.h/.cpp  ← অর্থ বিশ্লেষক (এলেন)

│   ├── error.h          ← ত্রুটি ব্যবস্থাপনা
│   └── main.cpp         ← মূল প্রোগ্রাম

├── examples/
│   ├── hello.bsc
│   ├── math_test.bsc
│   └── ...
└── README.md            ← এই ফাইল
```
