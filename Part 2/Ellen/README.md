## কাজের বিবরণ

পর্ব ২-তে Semantic Analyzer **`যতক্ষণ`** (while loop) ব্লকের মধ্যে চলকের ধরন ও স্কোপ পরীক্ষা করতে সক্ষম হয়েছে।

### পর্ব ২-এ নতুন কী আছে:
- `যতক্ষণ` লুপের শর্ত (`condition`) ধরন পরীক্ষা
- লুপ ব্লকের ভেতরে চলকের সঠিক স্কোপ যাচাই
- লুপে নিয়োগ (`assignment`) সঠিক কিনা পরীক্ষা

## উদাহরণ প্রোগ্রাম

### ১ থেকে ১০ যোগফল
```
ধরি সংখ্যা সীমা = ১০;
ধরি সংখ্যা যোগফল = ০;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= সীমা) শুরু
    যোগফল = যোগফল + গণক;
    গণক = গণক + ১;
শেষ

দেখাও "১ থেকে ১০ এর যোগফল:";
দেখাও যোগফল;
```
**আউটপুট:** `৫৫`

### ফ্যাক্টরিয়াল
```
ধরি সংখ্যা মান = ৫;
ধরি সংখ্যা ফ্যাক্টরিয়াল = ১;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= মান) শুরু
    ফ্যাক্টরিয়াল = ফ্যাক্টরিয়াল * গণক;
    গণক = গণক + ১;
শেষ

দেখাও "৫ এর ফ্যাক্টরিয়াল:";
দেখাও ফ্যাক্টরিয়াল;
```
**আউটপুট:** `১২০`

### ফিবোনাচি ধারা
```
ধরি সংখ্যা প্রথম = ০;
ধরি সংখ্যা দ্বিতীয় = ১;
ধরি সংখ্যা সীমা = ৮;
ধরি সংখ্যা গণক = ০;

দেখাও "ফিবোনাচি ধারা:";
দেখাও প্রথম;
দেখাও দ্বিতীয়;

যতক্ষণ (গণক < সীমা) শুরু
    ধরি সংখ্যা অস্থায়ী = প্রথম + দ্বিতীয়;
    প্রথম = দ্বিতীয়;
    দ্বিতীয় = অস্থায়ী;
    দেখাও দ্বিতীয়;
    গণক = গণক + ১;
শেষ
```
**আউটপুট:** `০, ১, ১, ২, ৩, ৫, ৮, ১৩, ২১, ৩৪`
