## কাজের বিবরণ

Semantic Analyzer (অর্থ বিশ্লেষক) হলো কম্পাইলারের তৃতীয় ধাপ। Parser থেকে পাওয়া AST যাচাই করে অর্থগত শুদ্ধতা নিশ্চিত করে।

### Semantic Analyzer যা করে:
- **চলক ঘোষণা যাচাই** — একই চলক দুবার ঘোষণা করা যাবে না
- **অঘোষিত চলক ধরা** — ঘোষণা ছাড়া চলক ব্যবহার করলে ত্রুটি
- **ধরন যাচাই (Type Checking)** — `সংখ্যা` চলকে `দশমিক` মান দেওয়া যাবে না
- **নিয়োগ যাচাই** — মানের ধরন সঠিক কিনা পরীক্ষা করে
- **প্রতীক তালিকা** (Symbol Table) তৈরি ও রক্ষণাবেক্ষণ

### ধরনের নিয়ম:
| চলকের ধরন | বৈধ মান | অবৈধ মান |
|-----------|---------|----------|
| `সংখ্যা` | `১০`, `৫`, `০` | `৩.১৪`, `"বাংলা"` |
| `দশমিক` | `৩.১৪`, `৫.৫`, `১০` | `"বাংলা"` |

## উদাহরণ প্রোগ্রাম

### সফল যাচাই
```
ধরি সংখ্যা প্রথম = ১০;
ধরি সংখ্যা দ্বিতীয় = ৫;
ধরি সংখ্যা ফল = প্রথম + দ্বিতীয়;
দেখাও "যোগফল:";
দেখাও ফল;
```
**আউটপুট:** `যোগফল:` → `১৫`

### বয়স যাচাই (If-Else)
```
ধরি সংখ্যা বয়স = ১৬;
যদি (বয়স > ১৭) শুরু
    দেখাও "আপনি ভোট দিতে পারবেন!";
শেষ
নাহলে শুরু
    দেখাও "আপনি ভোটের বয়স হয়নি।";
শেষ
```
**আউটপুট:** `আপনি ভোটের বয়স হয়নি।`

### ধরন ভুলের উদাহরণ (type_error.bsc)
```
ধরি সংখ্যা টাকা = ১০;
টাকা = ৫.৫;
```
**Semantic ত্রুটি:** `সংখ্যা` চলকে দশমিক মান দেওয়া যাবে না

### অঘোষিত চলকের উদাহরণ (undeclared_error.bsc)
```
ধরি সংখ্যা ক = ১০;
ক = ভূত + ৫;
```
**Semantic ত্রুটি:** `ভূত` চলক ঘোষণা করা হয়নি
