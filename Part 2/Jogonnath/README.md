পর্ব ২-তে Lexer পর্ব ১-এর সব ক্ষমতা রেখে **`যতক্ষণ`** (while loop) কীওয়ার্ড সমর্থন যোগ করেছে।

## উদাহরণ প্রোগ্রাম

### ১ থেকে ১০ এর যোগফল
```
ধরি সংখ্যা সীমা = ১০;
ধরি সংখ্যা যোগফল = ০;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= সীমা) শুরু
    যোগফল = যোগফল + গণক;
    গণক = গণক + ১;
শেষ

দেখাও "১ থেকে ১০ এর যোগফল:";
দেখাও যোগফল;
```
**আউটপুট:** `৫৫`

### ফ্যাক্টরিয়াল (৫ এর)
```
ধরি সংখ্যা মান = ৫;
ধরি সংখ্যা ফ্যাক্টরিয়াল = ১;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= মান) শুরু
    ফ্যাক্টরিয়াল = ফ্যাক্টরিয়াল * গণক;
    গণক = গণক + ১;
শেষ

দেখাও "৫ এর ফ্যাক্টরিয়াল:";
দেখাও ফ্যাক্টরিয়াল;
```
**আউটপুট:** `১২০`

### ফিবোনাচি ধারা
```
ধরি সংখ্যা প্রথম = ০;
ধরি সংখ্যা দ্বিতীয় = ১;
ধরি সংখ্যা সীমা = ৮;
ধরি সংখ্যা গণক = ০;

দেখাও "ফিবোনাচি ধারা:";
দেখাও প্রথম;
দেখাও দ্বিতীয়;

যতক্ষণ (গণক < সীমা) শুরু
    ধরি সংখ্যা অস্থায়ী = প্রথম + দ্বিতীয়;
    প্রথম = দ্বিতীয়;
    দ্বিতীয় = অস্থায়ী;
    দেখাও দ্বিতীয়;
    গণক = গণক + ১;
শেষ
```
**আউটপুট:** `০, ১, ১, ২, ৩, ৫, ৮, ১৩, ২১, ৩৪`

### উল্টো গণনা
```
ধরি সংখ্যা গণনা = ৫;
দেখাও "উল্টো গণনা:";

যতক্ষণ (গণনা > ০) শুরু
    দেখাও গণনা;
    গণনা = গণনা - ১;
শেষ

দেখাও "শেষ!";
```
**আউটপুট:** `৫, ৪, ৩, ২, ১, শেষ!`
