## উদাহরণ প্রোগ্রাম

### ১ থেকে ১০ এর যোগফল
```
ধরি সংখ্যা সীমা = ১০;
ধরি সংখ্যা যোগফল = ০;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= সীমা) শুরু
    যোগফল = যোগফল + গণক;
    গণক = গণক + ১;
শেষ

দেখাও "১ থেকে ১০ এর যোগফল:";
দেখাও যোগফল;
```
**আউটপুট:** `৫৫`

### ফ্যাক্টরিয়াল
```
ধরি সংখ্যা মান = ৫;
ধরি সংখ্যা ফ্যাক্টরিয়াল = ১;
ধরি সংখ্যা গণক = ১;

যতক্ষণ (গণক <= মান) শুরু
    ফ্যাক্টরিয়াল = ফ্যাক্টরিয়াল * গণক;
    গণক = গণক + ১;
শেষ

দেখাও "৫ এর ফ্যাক্টরিয়াল:";
দেখাও ফ্যাক্টরিয়াল;
```
**আউটপুট:** `১২০`
